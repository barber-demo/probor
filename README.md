# BARBER HOUSE — шаблон приложения для барбершопа

Мобильное веб-приложение (PWA): услуги и цены, мастера, онлайн-запись, контакты.
Ставится на главный экран телефона и открывается без адресной строки браузера.

Сейчас в `config.js` — **демо-данные вымышленного барбершопа**.

## Как устроен проект

| Файл / папка | Что это | Меняется под клиента? |
|---|---|---|
| `config.js` | Все данные барбершопа: название, цвета, услуги, мастера, контакты, график, способ записи | **Да** |
| `images/` | Фото: первый экран, услуги, мастера | **Да** |
| `index.html` | Движок приложения | Нет |
| `tools/build.py` | Скрипт сборки: иконки, манифест, кеш | Нет |
| `icons/`, `manifest.webmanifest`, `sw.js` | Создаются скриптом сборки | Автоматически |

## Как сделать приложение для нового барбершопа

1. Собрать данные клиента: название, адрес, телефон, мессенджеры, график, услуги с ценами и длительностью, мастера, фото.
2. Положить фото в `images/` (лучше `.jpg`, ширина 1200–1600 px).
3. Заполнить `config.js`. Если фото нет — `null`, приложение покажет аккуратную заглушку.
4. Запустить `python3 tools/build.py` — он проверит настройки и обновит иконки и манифест.
5. Выложить на хостинг (сейчас — GitHub Pages).

## Способы записи (`booking.mode`)

- `"demo"` — встроенная запись на демо-расписании. Заявки **никуда не отправляются**, только для показа.
- `"external"` — кнопки «Записаться» ведут в систему, которой барбершоп уже пользуется
  (YCLIENTS, DIKIDI и т. п.). Нужно указать `externalUrl` и `externalName`.
  Это рабочий вариант уже сейчас: записи попадают в CRM барбершопа.

## Важно перед коммерческим запуском

- Собственная запись с сохранением данных клиентов требует сервера, согласия на обработку
  персональных данных и политики конфиденциальности (152-ФЗ). Пока не реализовано.
- Фото и тексты клиента используются только с его разрешения.
